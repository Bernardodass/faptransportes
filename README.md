# FAP Transportes

Site institucional da FAP Transportes, transportadora de Guarulhos (SP), desenvolvido como trabalho freelance remunerado. No ar em https://faptransportes.com.

## O que é

Página única com as seções Início, A Jornada, Sobre, Serviços e Contato, em HTML, CSS e JavaScript puro, sem framework nem template.

- Layout responsivo (desktop e celular)

- Solicitação de orçamento e contato via WhatsApp com mensagem pré-preenchida

- Telefone clicável, endereço e horário de atendimento

- Mapa do Google Maps incorporado

- Hospedado na Vercel (configuração em vercel.json)

## Como rodar

Abra index.html no navegador ou sirva a pasta com um servidor estático, por exemplo npx serve .. Não há build nem dependências.
